Features

Easy for common tasks, with full access when you need it.

Friendly methods and types for everyday work, with the complete Telegram API one import away.

Async first

Built on asyncio from the ground up. It can also be used synchronously when a script is simpler that way.

Users and bots

Log in as a user account to do anything an official client can, or use a bot token as a faster Bot API alternative.

Type-hinted

Every method and type carries hints, so your editor autocompletes arguments and catches mistakes before you run.

Latest features

Gifts, Stories, forum Topics, Business accounts, paid media, reactions and boosts, with ready-made methods and handlers.

Full raw API

All 824 functions and 1,692 types of the MTProto schema are generated as Python classes and callable with invoke.

Fast crypto

Install the fast extra to add TgCrypto (C-accelerated encryption) and uvloop.

Examples

Short code for real tasks

Handlers react to updates, filters decide which updates they receive, and client methods do the work. There are 30 handler types, from messages to reactions to business messages.

bot.py 
from pyrogram import Client, filters

app = Client(
    "my_bot",
    api_id=12345,
    api_hash="0123456789abcdef0123456789abcdef",
    bot_token="123456:ABC-DEF...",
)


@app.on_message(filters.command("start"))
async def start(client, message):
    await message.reply(f"Hi {message.from_user.first_name}!")


@app.on_message(filters.photo)
async def photo(client, message):
    await message.reply("Nice picture.")


app.run()
userbot.py 
import asyncio
from pyrogram import Client


async def main():
    async with Client("my_account") as app:
        # Read the last 10 messages of your Saved Messages
        async for msg in app.get_chat_history("me", limit=10):
            print(msg.text)

        # Post a story
        await app.send_story("me", "sunset.jpg", caption="Evening")


asyncio.run(main())
raw.py 
import asyncio
from pyrogram import Client, raw


async def main():
    async with Client("my_account") as app:
        # Any method in the Telegram schema, even without a wrapper
        config = await app.invoke(raw.functions.help.GetConfig())
        print(config.dc_options[0])


asyncio.run(main())

Staying current

Telegram schema changes arrive as a pull request.

The low-level API is generated from Telegram's schema. A daily workflow checks for changes and prepares the update, so the library doesn't depend on anyone else's release schedule.

Watch

Every day, a GitHub Actions workflow compares Telegram Desktop's api.tl to the last snapshot.

Sync

If the schema changed, the new definitions are copied into the local schema file.

Rebuild and check

The raw API layer is regenerated, then lint and typecheck run against it.

Review

The workflow opens a pull request. A person reviews and merges it before any release.

New Telegram features are usable through raw as soon as the pull request is merged. Friendly methods like app.send_gift() are written by hand afterwards.
